## Key Collocations (Band 7+ markers)

### Cause and Effect
- give rise to / lead to / result in / bring about / contribute to
- stem from / arise from / originate from / be rooted in
- trigger / generate / produce / engender

### Importance
- play a pivotal role / play an indispensable part
- be of paramount importance / be of great significance
- carry considerable weight / hold substantial value

### Trend and Change
- a growing trend towards / an increasing tendency to
- a significant shift in / a remarkable transformation of
- experience a steady decline / undergo a gradual change

### Opinion and Stance
- hold the view that / contend that / maintain that
- it is widely argued that / it is commonly asserted that
- from my perspective / from my standpoint / in my view

### Problem and Solution
- tackle the issue / address the problem / combat the challenge
- implement measures / adopt strategies / take proactive steps
- alleviate / mitigate / reduce / minimize

## Band 7+ Sentence Patterns

### 1. Complex Sentences (variety is key)

**Concession + Main clause:**
- "Although [X], it is equally true that [Y]."
- "While [X] undoubtedly has merit, [Y] deserves equal consideration."
- "Despite the fact that [X], [Y]."

**Conditional:**
- "If [condition], then [result]."
- "Were [condition] to occur, [result] would follow."
- "Should [condition] arise, [result]."

**Relative clauses:**
- "Those who [action] tend to [result]."
- "[Noun], which [description], [main clause]."
- "Individuals who [action] are more likely to [result]."

### 2. Passive Voice (for academic tone)
- "It is widely believed that..."
- "It can be argued that..."
- "It has been demonstrated that..."
- "[Subject] is often considered to be..."
- "Measures should be taken to..."

### 3. Nominalization (formal academic writing)
- Instead of "People pollute the environment": "Environmental pollution has become a pressing concern."
- Instead of "The government should invest in education": "Government investment in education is essential."
- Instead of "Because technology develops quickly": "The rapid development of technology has led to..."

### 4. Cleft Sentences (emphasis)
- "It is [X] that [Y]."
- "What [X] is [Y]."
- "It is through [method] that [result] can be achieved."

### 5. Inversion (advanced structure)
- "Not only does [X], but it also [Y]."
- "Rarely has [X] been so [Y]."
- "Under no circumstances should [X]."
- "Only by [doing X] can [Y] be achieved."

### 6. Subordinate Clauses
- "Given that [X], [Y]."
- "Provided that [X], [Y]."
- "In light of [X], [Y]."
- "Owing to [X], [Y]."

## Grammar Features to Demonstrate (for Band 7+ GRA)

Must show at least 4-5 of these in a single essay:
1. Relative clauses (who, which, that, whose, where)
2. Conditional sentences (first, second, third conditional)
3. Passive voice
4. Modal verbs (would, should, could, might, may)
5. Perfect tenses (present perfect, past perfect)
6. Gerunds and infinitives
7. Participle clauses (reduced relative clauses)
8. Comparative and superlative structures
9. Cleft sentences
10. Inversion for emphasis
11. Concessive clauses (although, despite, while)
12. Nominalization

|-------|-------------|
| Nowadays | Today, currently, in contemporary society |
| Every coin has two sides | (Delete entirely — cliché) |
| With the development of society | In recent decades / In the modern era |
| More and more | An increasing number of / A growing proportion of |
| I think / I believe | I contend / I maintain / It is my view that |
| Very | Extremely, particularly, exceptionally |
| Big | Substantial, considerable, significant |
| Good | Beneficial, advantageous, favorable |
| Bad | Detrimental, adverse, unfavorable |
| Thing | Aspect, factor, element, issue |
| A lot of | A considerable number of, numerous, a multitude of |
| In a word | In conclusion, to summarize |
| First and foremost (overused) | Primarily, initially, most importantly |
