💡 听力同义替换技巧

1. 预读题目时标记关键词

在读题时间，圈出题目中的核心名词、动词和形容词，预判音频中可能出现同义替换。例如题目写 "financial support"，预判音频可能说 "funding" 或 "money assistance"。

2. 重点关注动词和形容词替换

雅思听力同义替换最常发生在动词和形容词上。如题目写 "improve"，音频可能说 "enhance / boost / upgrade"。建议系统背诵高频动词替换。

3. 注意否定词的同义表达

否定意义的同义替换是常见陷阱。如 "not enough" = "insufficient / inadequate"，"no longer" = "cease / discontinue"，"fail to" = "unable to / miss"。

4. 数字和频率的同义替换

如 "a third" = "33% / one in three"，"the majority" = "most / over half"，"twice" = "double / two times"。注意分数与百分比的转换。

5. 注意词性转换

同义替换不总是换词，有时是词性转换。如题目名词 "requirement"，音频动词 "require"；题目形容词 "accessible"，音频动词 "access"。

6. 选项题：先排除，再匹配

选择题中，先排除明显不符合的选项，然后对剩下的选项逐一匹配同义替换。注意干扰项往往用题目原词，正确答案往往用同义替换。
