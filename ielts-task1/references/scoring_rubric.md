# IELTS Task 1 Scoring Rubric

Task 1 is scored on four criteria, each worth 25%. The criteria are similar to Task 2, but Task Response (TR) is replaced by Task Achievement (TA).

## 1. Task Achievement (TA)

| Band | Description |
|------|-------------|
| 9 | Fully satisfies all requirements of the task. Clearly presents a fully developed response. Key features are highlighted and presented with detail. |
| 8 | Covers all requirements of the task sufficiently. Presents, highlights and illustrates key features/bullet points clearly and appropriately. |
| 7 | Covers the requirements of the task. Presents a clear overview of main trends, differences or stages. Clearly presents and highlights key features but could be more fully extended. |
| 6 | Addresses the requirements of the task. Presents an overview with information appropriately selected. Presents and highlights key features/bullet points but details may be irrelevant, inappropriate or inaccurate. |
| 5 | Generally addresses the task but the format may be inappropriate in places. Recounts detail mechanically with no clear overview. There may be no data to support the description. |
| 4 | Attempts to address the task but does not cover all key features. Format may be inappropriate. No clear overview. |
| 3 | Fails to identify all key features. May confuse key features with detail. Description may be irrelevant or inaccurate. |
| 2 | Answer is very limited. Barely responds to the task. |
| 1 | Answer is completely unrelated to the task. |

**Key TA indicators for scoring:**
- Is there a clear overview paragraph? (Without it, max Band 5)
- Are the most significant features identified and described?
- Is data selected appropriately (not every number described)?
- Is the word count met (150+)?
- Is the information presented accurately (correct data points)?
- Is the format appropriate (introduction → overview → details)?

## 2. Coherence and Cohesion (CC)

| Band | Description |
|------|-------------|
| 9 | Uses cohesion in such a way that it attracts no attention. Skilfully manages paragraphing. |
| 8 | Messages and ideas follow each other logically. All aspects of cohesion are well-managed. |
| 7 | Logically organizes information and ideas. Clear progression throughout. Uses a range of cohesive devices appropriately. Presents a clear central topic within each paragraph. |
| 6 | Arranges information and ideas coherently. Uses cohesive devices effectively, but cohesion within and/or between paragraphs may be faulty or mechanical. |
| 5 | Presents information with some organization but may be generally undeveloped. Relationships between ideas may be unclear or repetitive. |
| 4 | Presents information and ideas but with limited organization. Uses limited cohesive devices. |
| 3 | Does not organize ideas logically. Uses very limited cohesive devices. |
| 2 | Has very little control of organizational features. |
| 1 | Communication is impossible due to lack of language. |

**Key CC indicators for scoring:**
- Is information logically organized (intro → overview → details)?
- Are cohesive devices used naturally?
- Does each paragraph have a clear focus?
- Is referencing (this, these, it, which) used correctly?
- Is there smooth progression between paragraphs?

## 3. Lexical Resource (LR)

(Same as Task 2 rubric — see Task 2 scoring rubric for full details)

**Key LR indicators specific to Task 1:**
- Is there a range of trend/comparison vocabulary?
- Are less common words used correctly (collocation)?
- Is there variety in expression (not repeating "increase" five times)?
- Are spelling and word formation correct?
- Are paraphrases of the prompt accurate?

## 4. Grammatical Range and Accuracy (GRA)

(Same as Task 2 rubric — see Task 2 scoring rubric for full details)

**Key GRA indicators specific to Task 1:**
- Is there a mix of sentence types?
- Are tenses used correctly (past for historical data, present for current data)?
- Is passive voice used appropriately (especially for process diagrams)?
- Are comparisons grammatically correct (comparatives, superlatives)?
- Are articles and prepositions correct with data references?

## Overall Band Calculation

Overall = average of (TA + CC + LR + GRA), rounded to nearest 0.5 or whole band.

**Key reminders:**
- Missing overview = automatic TA cap at Band 5
- Under 150 words = penalty
- Personal opinion included = penalty
- Inaccurate data = significant penalty
- Describing every single data point = not necessary and wastes words; select strategically
